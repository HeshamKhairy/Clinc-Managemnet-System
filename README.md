# Clinc-Managemnet-System


This is a simple Clinic Management System written in C. The program provides two modes: Admin Mode and User Mode.

Features
Admin Mode
Requires password login (default: 1234, 3 attempts max).

Add new patient records (name, age, gender, unique ID).

Edit existing patient records using patient ID.

Reserve appointment slots for patients (5 predefined time slots).

Cancel existing reservations.

User Mode
No password required.

View patient records using patient ID.

View today's reservations with patient IDs and time slots.

Usage
Run the program and follow on-screen instructions to navigate between modes and perform operation
